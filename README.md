# make-knowledge-cards

一个开源的 AI Skill（技能）：把用户粘贴的章节文本或本地 **Markdown / TXT** 文件，转换成 **5~8 张结构化知识卡**，用于复习、记忆和自测。

## 1. 项目解决什么问题

学习材料（章节、讲义、笔记、科普、教材）往往内容密集、信息重复、重点不突出，复习时难以快速抓住关键点，记忆效率低。本 Skill 解决的问题是：

- **信息过载**：长文本里真正的知识点被铺垫、客套话和重复段落淹没，难以提取。
- **复习困难**：没有结构化的要点卡片，复习时只能重读原文。
- **记忆无抓手**：缺少「一句话核心 + 通俗解释 + 例子/自测」的轻量记忆单元。

它把一段学习文本自动拆解为一张卡只讲一个知识点的结构化卡片，让复习、记忆和自测变得快速、可操作。

## 2. 主要功能

- **自动提炼知识点**：通读全文，筛选真正重要的核心概念、机制、流程、结论、对比和规律，忽略客套话与铺垫。
- **生成结构化知识卡**：每张卡固定四个部分——标题、核心知识、简明解释、例子或自测问题。
- **一张卡一个知识点**：禁止把多个概念硬塞进一张卡；相似或从属知识点可合并，但合并后仍只讲一件事。
- **自动去重**：同一知识点在原文多处出现时只保留一次，删除重复表达。
- **不编造信息**：所有卡片内容都能在原文找到依据，不补充、不联想、不臆造。
- **不强行凑数**：信息不足时给出少而准的卡片并说明；几乎无可提炼内容时明确告知，不硬造卡片。
- **两种输入方式**：直接粘贴文本，或提供本地 `.md` / `.txt` 文件路径。
- **两种输出方式**：默认在对话中输出 Markdown 卡片；也可保存为 `.md` 文件。
- **文本驱动、零依赖**：由 AI 直接完成处理，无需额外脚本或第三方库。

### 不支持的输入

网页抓取（网址）、PDF 文件、Anki 卡片格式、图形界面（只产出 Markdown 文本卡片）。

## 3. 安装方法

本 Skill 是文本驱动型的，**没有运行时依赖，无需 `pip install` 任何包**，安装即「放置文件夹」。

**Step 1：定位 Skill 根目录**

将 `skills/make-knowledge-cards/` 整个文件夹复制到你的 Agent 环境的 Skill 根目录。默认位置为现有 `workspace/.user_skills` 目录（以实际环境的路径为准）：

```
<environment-parent>/workspace/.user_skills/make-knowledge-cards/
```

如果所用 Agent 支持从项目内加载 Skill，也可以直接引用本项目中的 `skills/make-knowledge-cards/` 路径。

**Step 2：确认目录结构完整**

Skill 只需两个文件：

```
make-knowledge-cards/
├── SKILL.md            # Skill 定义：frontmatter（name/description/license）+ 工作流指令
└── agents/
    └── openai.yaml     # Agent 配置（模型、指令、工具、输出格式）
```

**Step 3（仅开发/校验时需要）**：运行官方校验工具 `quick_validate.py` 需要 Python 与 PyYAML：

```powershell
python -m pip install pyyaml
python "…\skill-creator-for-work\scripts\quick_validate.py" "skills\make-knowledge-cards"
# → Skill is valid!
```

## 4. 使用方法

### 方式一：直接粘贴文本

在支持该 Skill 的 Agent 中，粘贴章节文本并说明意图即可：

> 帮我把下面这段内容做成知识卡：
> （粘贴章节文本……）

### 方式二：提供本地文件

给出本地 `.md` 或 `.txt` 文件路径：

> 把 `test/map_projection.md` 做成知识卡

### 输出交付

- 默认在对话中直接输出 Markdown 卡片列表，开头标注「共 N 张卡」。
- 若要求保存，输出为一个语义化命名的 `.md` 文件（如 `knowledge-cards.md`），放入当前项目目录。

### 示例请求

| 你说 | Skill 做的事 |
|---|---|
| “把这段科普做成知识卡” | 提炼知识点 → 去重 → 输出 5~8 张卡 |
| “把 `xxx.txt` 改成复习卡片” | 读取文件 → 提炼 → 去重 → 输出卡片 |
| “保存成文件” | 额外生成 `.md` 文件交付 |

## 5. 输入 / 输出示例

### 输入（节选，科普章节，完整见 `test/water_states.md`）

> 水在 0 摄氏度时结冰，从液态转变为固态的冰。冰的密度比水小，所以冰总是浮在水面上……当温度升高到 100 摄氏度时，水会沸腾并变成水蒸气，这一过程叫汽化。汽化有两种方式：沸腾和蒸发……

### 输出（节选，完整版见 `test/out/water_states_cards.md`）

```
共 6 张卡

### 卡片 1：水的三种状态
- 核心知识：水在固态、液态、气态之间随温度变化而相互转化……
- 简明解释：……
- 例子或自测问题：……

### 卡片 3：汽化：沸腾与蒸发
- 核心知识：液态水变成水蒸气叫汽化，分为沸腾和蒸发两种方式。
- 简明解释：……
- 例子或自测问题：夏天晾晒湿衣服，衣服上的水通过蒸发变成水蒸气跑掉。
```

### 真实用例：文学作品《我与地坛》节选

对史铁生《我与地坛》节选运行本 Skill，输出 7 张卡（见项目根 `knowledge-cards.md`），例如：

```
### 卡片 5：儿子的不幸在母亲那儿加倍
- 核心知识：儿子的不幸在母亲那儿总是要加倍的；母亲默默作了最坏的准备，却从未说过"你为我想想"。
- 简明解释：……
- 例子或自测问题：例子：母亲"从来没有对我说过：'你为我想想'"。
```

## 开发与验证

- 初始化：使用官方 `skill-creator-for-work` 的 `init_skill.py` 创建骨架，随后自定义 `SKILL.md` 与 `agents/openai.yaml`。
- 校验：`quick_validate.py` 检查 frontmatter 与命名规范（`Skill is valid!`）。
- 测试：`test/` 目录包含四类输入（科普、重复文本、信息不足、结构化长章节）及对应输出，覆盖了去重、不凑数、多知识点等关键场景。
